# Implementation Plan: SentinelPulse — Market Intelligence & News Impact Engine

## Overview

SentinelPulse transforms raw financial news from six sources into structured, evidence-backed market intelligence for AlphaForge's multi-factor signal engine and ml-service. This plan implements the full transformation pipeline:

```
Raw News → NormalizedArticle → NewsCluster → Entities → NewsEvents
→ Sentiment → Importance → MarketImpact → HistoricalReaction
→ FeatureVector → TrainingSample → AlphaForge / ml-service
```

The implementation proceeds in 28 phases, each building directly on the previous. All tasks are TypeScript (Node.js 20 LTS) unless noted. The design document is the authoritative specification for all implementation details.

    - _Requirements: Req 4.1–4.11_

## Notes

- Tasks marked with `*` are optional and can be skipped for a faster MVP — they do not block any subsequent tasks
- Each task references specific requirements for traceability; granular sub-requirement numbers (e.g., Req 3.5) are used where applicable
- Checkpoints at Phases 7, 10, 13, 20, and 21 ensure incremental validation before building the next layer
- All property tests use `fast-check` with a minimum of 100 iterations per property
- `LookAheadBiasError` is always terminal — never retried — ensuring data integrity across the entire pipeline
- The Scrapling sidecar (Python) is isolated so it can be updated independently of the main TypeScript service
- Workers are stateless; all job state lives in BullMQ/Redis, enabling horizontal scaling without coordination
- The design document is the authoritative specification; this task list is an execution roadmap — when in doubt, defer to the design
